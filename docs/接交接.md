20. ⚠️ **门里写"不产生副作用"的断言，要用「前后差值 == 0」，不要用「总数 == 某个数」**
    —— 总数型断言会把实现里**固有的、无关的**消息一起算进来 → 假红（v2.11.0 踩过一次）
21. ⚠️ **启动 9620 只用两条路**：① 人类双击 `启动-01R-FLUX服务重启.bat`
    （进程归属 explorer，与 agent 会话无关，**唯一耐久的方式**）；
    ② agent 侧用**后台任务**（`run_in_background`）—— 但**它绑定当前会话**，会话结束服务就没了。
    **别试** `schtasks` / WMI `Win32_Process.Create` / `explorer.exe <file>`：
    被安全策略拉黑或静默失效；`DETACHED_PROCESS|CREATE_BREAKAWAY_FROM_JOB` 也**照样被回收**。
22. ⚠️ **本机探活必须绕代理**：`curl --noproxy '*'`，或给脚本加 `NO_PROXY='*'`。
    本机有 `http_proxy=127.0.0.1:2685`，走代理探 `127.0.0.1:9620` 会拿到 **502** → 误判"服务挂了"
23. ⚠️ **改一个"默认行为"时，先问「有多少道门依赖这个默认值」** ——
    v2.12.0 把「发提示词直接出图」改成「先确认」，**4 道既有门同时红**（cancel 1 项 / p0 7 项），
    但**没有一处是实现坏了**：它们都用「发一句 → 断言进队列」验证各自的逻辑（去重/上限/回执/取消）。
    正确做法是**改门**（`bot.confirm_enabled = False`），**不是改断言** ——
    改断言会把真缺陷一起改掉。同时**必须**另留一道门钉住"线上默认值"（`t_default_on`
    断言 `fb.CONFIRM_SUBMIT is True`），否则测试后门一多，默认值被改都没人发现。
    详见 `PITFALLS.md` 同名条目（2026-09-28）
24. ★ **永远不要为了让功能生效，去改「记录事实」的字段**（v2.13.0 新增）
    —— 实例：为了让 Qwen 能上 B 链，最省事的做法是把 `servers.json` 的
    `commercial_ok: false` 改成 `true`（一行搞定）。**这是错的**：
    该字段记录的是**许可证允不允许商用**这个事实，改了它，后来者就再也分不清
    「模型本来就能商用」和「有人为了放行把事实改成了谎话」，而两者法律含义完全不同。
    → 正确做法：**事实字段不动，另加一个正交的「决定」字段**
    （`expose_to_customers` + `expose_note`），判据变**或关系**。
    配套三件：**留证**（门断言 `expose_note` 非空）、**可见**（选中时打 `WARNING`）、
    **可回滚**（把决定字段改回 `false`，事实字段没被动过）。
    ★ 可复用判据：**要改的字段记录的是事实（版本号/许可证/实测值/时间戳），
    而你要它表达的是决定或期望 —— 加新字段，不要改事实。**
    与硬约束 1 所属的「声明 ≠ 约束」是镜像：那边是"没人读"，这边是"读的是谎话"。
    详见 `PITFALLS.md` 同名条目（2026-09-28）
25. ★ **`Edit` 工具报 success ≠ 已落盘**（2026-09-28 实测，本机间歇发生）
    —— 同一批多个 edit，出现过「只落盘一部分、其余仍报 success」。
    与「`git commit` rc=0 但 HEAD 未变」同源（本机写入不可靠）。
    → **改完必须复核**：`grep -c` 关键串 / `sed -n 'Np'` 看那一行 / `md5sum` 比对。
    **不看复核结果就宣称"文档已更新"= 假绿**（第 12 号陷阱家族）。

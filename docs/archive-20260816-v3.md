## 本次归档变更摘要

**v1.7 — 飞书"图图"对话式出图机器人**（从单向通知器升级为可对话出图）

用户要求：做成能对话的出图机器人——在飞书里发提示词，它生成后回传图片，并借鉴转录机器人"小白"的实现方式。

- 🤖 **`manager/feishu_bot.py`**（新增）：WebSocket 长连接监听 P2P 私聊（`lark_oapi.ws.Client`，对齐转录bot feishu_channel 范式）
  - 收到文本 → `scheduler.submit(open_id, prompt)`：中文自动翻译、配额检查、去重、入队（复用现有队列）
  - 确认回执（任务号 + 用量）；每用户最多 1 个在途任务；斜杠命令给提示语
  - 轮询线程检测 job done → 上传图片到飞书 → 发送图片消息回传；失败/服务器down 异常兜底
- 🖼️ **`manager/feishu_notify.py`**：新增 `upload_image()` / `send_image()` / `send_image_direct()`（飞书图片上传 `/open-apis/im/v1/images` + 图片消息发送）
- 🗄️ **`manager/flux_db.py`**：新增 `user_ensure()`（飞书 open_id 即 user_id，首次自动建用户）
- 🔌 **`manager/flux_service.py`**：主入口集成 bot 启动（凭证从 .env 读，未配置则不启动）
- ⚙️ `.gitignore`：新增 `manager/flux_service.out`（nohup 运行日志）

**设计决策**：同进程内嵌直接调 scheduler（不走 HTTP）；owner（自己）通过 bot 无限量；首版仅 P2P 私聊、纯文生图。

**验证**：图片回传链路实测通过（飞书收到测试图）；对话逻辑模拟通过（确认/在途拦截/配额/完成后回图）；服务重启 bot 激活；web 不受影响（本地 9620 + 公网 flux.zhuanlu.xyz 均 HTTP 200）。

**改动文件**：`README.md`、`CHANGELOG.md`、`.gitignore`、`docs/`（SPEC/ARCHITECTURE/TEST_PLAN/PITFALLS/PROGRESS）、`manager/feishu_bot.py`（新增）、`manager/feishu_notify.py`、`manager/flux_db.py`、`manager/flux_service.py`

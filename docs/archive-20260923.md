## 本次归档变更摘要

**一句话**：把「朋友打开公网看到旧页面」这个长期问题查到根（三个独立缺陷叠加）并修掉；
给商户后台开了独立公网域名 + 轮换弱口令；产出飞书机器人「图图」的完整互动设计方案。

### 三个根因（详见 `PITFALLS.md` 同日 3 条）

1. **隧道从未真正重启** —— `cloudflared` 启动时把 ingress 读进内存后不再读盘。
   实测进程停在 09-20 启的实例，`config.yml` 是 09-22 改的 → 公网走旧 ingress（指向 9620 旧页面）
2. **`Start-Process` 带日志重定向必抛**「重复的键 `https_proxy`」→ 只能退回带控制台窗口启动
   → **窗口一关服务就死**（实测 3000 反复"起来了又没了"）
3. **数组 splatting 让 `[switch]` 参数全绑不上** → `-NoPause` 失效 → 子脚本 `pause` **卡死编排器**
   → 隧道那一步**从未执行**；且 `-Restart` 也失效（"强制重启"从未发生）

### 验收判据换代

从「活体」（进程在不在 / HTTP 200）换成「**身份 + 新鲜度**」：
- 隧道：新进程启动时间 **≥** `config.yml` 的 mtime
- 公网：`<title>` **必须等于**目标站点本机 `<title>`，且**显式识别"等于旧上游 9620"**

证据：Playwright 真浏览器实测 `公网 == 3000 → True`，两张截图字节数一致。

### 新增 / 安全

- 新增 `docs/图图-飞书完整互动-设计方案.md`（差距分析 + P0-P6 + 验收标准 + 3 个已拍板决策）
- 新增对外域名 `flux-admin.zhuanlu.xyz` → `localhost:9620`
- 新增 `image-platform/重启隧道.bat`
- **`WEB_ADMIN_TOKEN` 轮换**为 20 位强口令（旧值 `flux-admin-2026` 在 README/SOP 里随处可见）；
  实测旧口令 `GET /api/admin/users` → **403**，新口令 → 200

## 本次归档变更摘要

将小红书场景的 FLUX 部署沉淀为**通用 FLUX 文生图服务项目**，与具体业务解耦，可服务所有文生图需求。核心内容：

- **server/**：批量文生图 `gen_flux.py` + 一键启动 `start_gen.sh` + curl 流式下载 `dl_curl.sh`
- **local/**：开机看门狗 `flux_gen_watchdog.py`（对标转录 bot 机制）
- **example/**：通用提示词模板 `prompts.example.json`
- **docs/**：5 份核心文档
- 密钥环境变量化（HF_TOKEN 不硬编码，防 GitHub 泄露）

# 图图使用说明（飞书对话式出图）

> 版本 **v2.12.0** · 2026-09-28
> 图图 = flux-t2i-server 内置的飞书机器人。**私聊发一句话 → 确认一下 → 出图**，也能发命令调参数。

---

## 一、最简用法（**多一步确认**）

**在飞书私聊里直接发一句中文**，例如：

```
一只橘猫坐在窗台上，夕阳，电影感
```

图图**不会立刻出图** —— 它先把这句回给你确认（因为用户发来的消息并不都是出图提示词）：

```
🤔 要把这一句作为生图任务提交吗？
「一只橘猫坐在窗台上，夕阳，电影感」

本次参数：1 张 · 比例 默认 · 模型 默认
回「是」开始出图 / 回「否」放弃
（5 分钟内有效；不回也没关系，不会扣额度）
```

你回 **「是」**（`好的` / `ok` / `确认` / `提交` 都行）→ 它才开始：

1. 回「⏳ 收到！正在解析提示词…（中文会先翻译成英文，通常十几秒）」
2. 翻译成英文提示词（**你不用自己写英文**）
3. 排队生成 → 完成后**图片直接回到对话里**，并附一条「✨ 已生成，请查收！」

| 你回什么 | 结果 | 扣额度吗 |
|---|---|---|
| 「是」「好的」「ok」「确认」「提交」「出图」 | 开始出图 | 扣 |
| 「否」「算了」「不用」「放弃」 | 放弃 | **不扣** |
| 别的文本（包括直接发下一句提示词） | 上一句作废 → 新的一句**重新确认** | **不扣** |
| 什么都不回（5 分钟后过期） | 自动作废 | **不扣** |

> ⚠️ **确认词要"完整一句"**：「好」算确认，但「好可爱的一只猫」**不算** ——
> 后者会被当成一句**新的提示词**再问你一次（刻意如此，免得把你的提示词吃掉）。
>
> 💡 觉得确认多余？服务端设 `FIGU_CONFIRM_SUBMIT=0` 可关掉（恢复「发一句就出图」）。
>
> 确认之后中文翻译最坏要约 68 秒，所以会有两条回执。**先回执再干活**是刻意的设计
> （否则屏幕上什么都没有，你会以为机器人坏了）。

## 二、命令速查

**中文裸命令**（对齐小白的用法，直接发就行）；**斜杠写法也接受**。

### 查看类

| 命令 | 作用 |
|---|---|
| `帮助` / `help` / `/help` | 命令清单 |
| `我的任务` / `我的排队` / 裸 `取消` | 列出我在途的任务（编号 + 提示词 + 状态 + 短号） |
| `参数` / `/params` | 看**本会话**当前的默认比例 / 张数 / 模型 |
| `额度` / `/quota` | 看套餐与本月用量，以及**有没有绑定**

### 参数类（改了之后就**一直生效**，存在库里，重启也不丢）

| 命令 | 作用 |
|---|---|
| `比例 16:9` / `/size 16:9` | 出图比例。可选：`1:1` `16:9` `9:16` `4:3` `3:4` |
| `张数 3` / `/n 3` | 一次出几张（**上限 4**） |
| `模型 klein` / `/model dev` | 换模型。可选：`klein` / `dev` / `qwen`（也接受完整 model id） |

⚠️ **参数是"按会话"记的**：你在**私聊**里设的「张数 3」不会影响你在**群里**、
也不会影响**别人**。反过来也一样。

### 取消类

| 命令 | 作用 |
|---|---|
| `取消 01` / `取消01` | 按 `我的任务` 列表里的序号取消 |
| `取消 3ada124e` | 按 job_id 短号取消（序号漂移时的退路） |

**取消的语义**（三种状态都能取消，行为不同）：

| 原状态 | 取消后 |
|---|---|
| 排队中 | 从队列里拿掉，**不占用 GPU** |
| 生成中 | **撤不回来**（GPU 已经在跑了）；跑完**丢弃产物**，不会发给你 |
| 等待中（服务器离线） | 从等待池拿掉，服务器上线后**不会再跑它** |

> ⚠️ **取消不退还额度**（与网页端同一口径：用完即消耗，防止"删了重传刷额度"）。

### 绑定类

| 命令 | 作用 |
|---|---|
| `绑定 XXXXXXXX` / `/bind XXXXXXXX` | 用激活码绑定，与**网页端共享同一份额度** |

**为什么要绑定**：不绑定时图图给你一份独立的免费额度；绑定后你在飞书和网页
**用的是同一份额度**（在网页买的套餐，飞书这边也能用）。

绑错了/换号？再绑一次同一个码即可（会并入同一个账户，**不会重复建账**）。

## 三、多图：一次翻译、多张候选

设了 `张数 3` 之后，后面每句话都出 3 张。

**这 3 张是"同一句话的 3 个候选"**，不是 3 句不相干的话 ——
提示词只翻译**一次**，第 2、3 张复用同一份英文，只是**随机种子不同**。
（如果你想要"3 个不同的构图"，把它们分成 3 句话发，或者自己把差异写进提示词。）

## 四、群聊（**未上线**）

群里用法与私聊相同：**@图图 + 一句话**。

但**目前未上线**（代码已就绪，还差飞书后台配置）：
- 现在把图图拉进群，**@它不会有任何反应** —— 这是设计如此（安全默认），不是坏了
- 上线步骤见 `docs/待办-群聊上线-20260928.md`

上线后的规则（**代码已钉住**）：
1. **只有在白名单里的群**才服务（默认白名单为空）
2. **必须 @图图本人** —— 群里 @别人 的消息**不会**被响应
3. 群里发起的任务，结果**回到群里**并只 @ 发起人（不丢进私聊、不 @ 全群）

## 五、常见问题

**Q：为什么发一句话不直接出图，还要我回「是」？**
v2.12.0 起加的这一步 —— 发给图图的消息**并不都是生图提示词**（随口一句、打错字都可能）。
不确认就直接出图会**白扣一次额度**、出一张毫不相干的图。
嫌麻烦？服务端设 `FIGU_CONFIRM_SUBMIT=0` 可关掉（恢复旧行为）。

**Q：确认时显示「3 张」，我中途把张数改成 1 了，最后出几张？**
按**确认时显示的**出 —— 3 张。确认消息里的参数是**那一刻的快照**，显示什么就提交什么。
（刻意如此：否则会出现"说 3 张、实际出 1 张"，系统说的和做的不一致。）

**Q：发了没反应？**
先看你是不是在**群里**（群聊未上线，见 §4）。私聊正常；若是私聊，看下方「额度」。

**Q：「你有一个任务还在生成中，请稍候再发～」？**
一次只能有一个在途任务（防止误连点出一堆图）。等它出完，
或者发 `我的任务` 看是哪张，`取消 01` 掉再发。

**Q：「当前在途任务较多，这次没有提交」？**
全站同时在跑的任务太多了。**这次没扣你额度**，稍后再发一次即可。

**Q：图没收到？**
若图图回了「❌ 生成完成但图片回传失败」，去网页 `flux.zhuanlu.xyz` 找同任务号下载。

**Q：翻译出来不是我想要的？**
把画面细节写具体（主体 / 动作 / 场景 / 光线 / 风格），例如
「一只橘猫**趴在木窗台**上，**夕阳逆光**，**电影感**，暖色调」。
图图走的是 FLUX 的提示词方法论，具体的名词比抽象形容词有效得多。

**Q：额度怎么看？**
发 `额度`（或 `/quota`），会显示套餐、本月已用量、以及**你是 owner / 已绑定 / 未绑定**。

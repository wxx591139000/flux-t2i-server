## 二、变更摘要

### 1) Qwen-Image-2.1 参考图/编辑优化（resident 侧，真机 8/8 验证）

| 改动 | 解决什么 |
|---|---|
| `DIM_MULTIPLE` 16→32 | 对齐官方 7 档尺寸（分辨率档位错位） |
| 新增 `_edit_follow_dims` | `/edit` 不传尺寸时画布跟随参考图宽高比（**修灰边根因**） |
| `_prepare_ref_image` 加 canvas 参数 | 画布可非方形，默认方形不变（向后兼容） |
| transparent 套官方 RGBA 模板 | 输出真透明图（alpha.min()==0） |
| `DEFAULT_MODEL_DIRS` 补 qwen 路径 | 修下拉框漏 Qwen |
| `start_resident.sh` 持久化 expandable_segments | 修 32G 显存 OOM |

**显存实测结论**（`tools/_qwen_vram_probe.py`）：1/2/3 图 = 20/25/30GB，4 图 OOM，单图 ≈4.8GB
→ **32G 够用，安全上限 3 张参考图**，不必克隆 48G。

### 2) 飞书图图参数状态机（新功能）

- `manager/figu_state.py`：纯逻辑、无 IO 的状态机，判「这条文本是否对上一次提问的回答」
- 配套门 `test_figu_confirm.py` / `test_figu_group.py` / `test_figu_params.py`

### 3) B 链任务状态误报修复（前后端配合）

- **隐患 B（后端）**：`flux_queue.py` 任务 `done` 时清空 `error` 字段（消除 `[SERVER_DOWN] [RETRY:N]` 残留误导）
- **隐患 A（前端，image-gen-site 独立仓）**：新增 `unreachable` 状态，
  区分「服务不可达」与「任务真失败」——服务重启窗口内不再误报「任务不存在/3 失败」

### 4) 上线排查修复（两处根因）

- `flux_server_manager.py` probe 加 `printf '\n'`（修 curl 无尾换行黏连 `MODELS_BEGIN` → 探活误判 `resident=False`）
- `servers.json` flux7 地址修正（`connect.westd.seetacloud.com:36832`）+ `offload=model`

## 本次归档变更摘要

**v1.6 — 新增两份使用 SOP 文档**（纯文档变更，无代码改动）

用户要求分别写一份详细的**商家使用 SOP** 和**用户使用 SOP**，并命名为中文文件名（含「flux服务」前缀）。

- 📘 **`docs/flux服务-商家使用SOP.md`**：商户经营客户套餐的完整 SOP
  - 登录商户中心（`X-Admin-Token` = `WEB_ADMIN_TOKEN`，存 localStorage 免重复登录）
  - 核心概念：激活码=账户=一客户，多设备共享一份套餐
  - 生成激活码开新客户（数量 1-100 / 天数 0-365 / 套餐 / 备注）
  - 客户/账户管理：改套餐、设 owner 无限、下钻看设备、搜索高亮
  - 激活码清单（复制/改备注/到期/跳账户）、最近任务、异常排查速查表
  - API 批量操作 curl 示例 + 安全约定
- 📗 **`docs/flux服务-用户使用SOP.md`**：普通用户从零到生成图的完整 SOP
  - 身份 Token 认知（换设备会变）、5 步生成图（支持中文提示词自动翻译）
  - 套餐与额度（default/basic/pro，提交即扣 1 张）
  - 激活码「激活/绑定账户」两种场景（新客户开通 vs 换设备绑定共享套餐）
  - FAQ 表 + API 调用示例 + 隐私安全
- 更新 `README.md`（v1.6 + 新增「使用文档」索引）、`CHANGELOG.md`（v1.6 条目）、`docs/PROGRESS.md`（v1.6 里程碑）

**改动文件**：`README.md`、`CHANGELOG.md`、`docs/PROGRESS.md`、`docs/flux服务-商家使用SOP.md`（新增）、`docs/flux服务-用户使用SOP.md`（新增）

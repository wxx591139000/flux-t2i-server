⚠️ **本轮最容易踩的 7 个坑（都是实际踩过的）**

1. ★ **永远不要为了让功能生效，去改「记录事实」的字段**（v2.13.0 新增）。
   实例：为了让 Qwen 上 B 链，最省事的是把 `commercial_ok: false` 改成 `true` —— **这是错的**。
   → 正确做法：**事实字段不动，另加一个正交的决定字段**（+ `expose_note` 留证 + `WARNING` 可见）。
   门会拦住它：`tests/test_commercial_gate.py::test_registry_still_declares_qwen_noncommercial`。

2. **命令判据既不能放宽，顺序也不能挪**（图图主用法是"发一句话出图"）：
   顺序错 → 命令被当提示词**真扣额度出废图**；判据松 → 吞掉正常提示词。

3. **判据里出现 `status in (...)` / `phase in (...)`，每加一个状态都要回头审全部条目**。
   ★ **内存态集合（`set`/`dict`）最易漏**。→ 修法：同一语义判据收敛成常量（`FEISHU_TERMINAL_PHASES`）。

4. **改 `.py` / `.env` / `servers.json` 后必须重启 9620**（都是启动时读一次）。
   判据：① `/health` uptime 远小于代码 mtime ② 新端点返回纯文本 404。
   重启后跑 `py -3.11 tools\check_stale.py` 自证新鲜度。

5. **`& script.ps1 @数组` 调子脚本会静默失效**（`[switch]` 绑不上 → `-NoPause` 失效 → `pause` 卡死编排器）。
   一律用**显式具名参数**。

6. **★ AI 环境无法起常驻服务**（v2.14.0 实锤）：PowerShell 工具 `Start-Process` 起 python 被安全拦截；
   Bash `run_in_background` 起的进程随对话轮次被回收。**唯一可靠常驻 = 用户桌面双击 `.bat`**
   （父进程挂 `explorer.exe`）。排查时反复 `Start-Process` 会留「幽灵 python 进程」干扰后续 `.bat`，
   必须先清理干净再让用户双击。

7. **改一个"默认行为"时，先问「有多少道门依赖这个默认值」** —— v2.12.0 改「先确认」后 4 道门同时红，
   但没一处是实现坏了。正确做法是**改门**（`bot.confirm_enabled = False`），**不是改断言**。

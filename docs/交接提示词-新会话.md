⚠️ **本轮最容易踩的 9 个坑（都是实际踩过的）**

1. ★ **中间层「瘦身」会静默丢字段**（v2.15.0）：`_api_models` 把上游对象重建成 5 字段 slim，
   把 `supports_edit`/`capabilities` **丢了** —— 而注释还给了个错误的可信解释（"上游版本旧"）。
   → 判据：**凡"重建上游对象"的地方都是隐式白名单**，新增"下游要靠它判断"的字段要回头审。
   门会拦它：`tests/test_web_models_passthrough.py`（删字段必红）。

2. ★ **能力字段「缺失」≠「不支持」**：缺失给 `None`（不是 `False`）；
   前端 `=== false` 才禁用，`undefined` 放行给上游硬闸。

3. ★ **永远不要为了让功能生效，去改「记录事实」的字段**（v2.13.0）。
   实例：为了让 Qwen 上 B 链，最省事的是把 `commercial_ok: false` 改成 `true` —— **这是错的**。
   → 正确做法：**事实字段不动，另加一个正交的决定字段**（+ `expose_note` 留证 + `WARNING` 可见）。

4. ★ **本机跑 `tests/run_all.py` 必须前置清空** `CODEBUDDY_SAFE_DELETE_BULK_STATE_DIR=` ——
   WorkBuddy 注入的 **Python 级**删除钩子（`sitecustomize.py`，非 shell 别名）会拦批量删除
   → 某测试**单跑绿、进 run_all 红**。**不是代码回归**，别去改代码。
   正确命令：`CODEBUDDY_SAFE_DELETE_BULK_STATE_DIR= py -3.11 tests/run_all.py`（→ 27/27）

5. **命令判据既不能放宽，顺序也不能挪**（图图主用法是"发一句话出图"）：
   顺序错 → 命令被当提示词**真扣额度出废图**；判据松 → 吞掉正常提示词。

6. **判据里出现 `status in (...)` / `phase in (...)`，每加一个状态都要回头审全部条目**。
   ★ **内存态集合（`set`/`dict`）最易漏**。→ 修法：同一语义判据收敛成常量（`FEISHU_TERMINAL_PHASES`）。

7. **改 `.py` / `.env` / `servers.json` 后必须重启 9620**（都是启动时读一次）。
   判据：① `/health` uptime 远小于代码 mtime ② 新端点返回纯文本 404。

8. **★ AI 环境无法起常驻服务**（v2.14.0 实锤）：PowerShell `Start-Process` 起 python 被安全拦截；
   Bash `run_in_background` 起的进程随对话轮次被回收。**唯一可靠常驻 = 用户桌面双击 `.bat`**
   （父进程挂 `explorer.exe`）。排查时反复 `Start-Process` 会留「幽灵 python 进程」，
   必须先清理干净再让用户双击。

9. **改一个"默认行为"时，先问「有多少道门依赖这个默认值」** —— v2.12.0 改「先确认」后 4 道门同时红，
   但没一处是实现坏了。正确做法是**改门**（`bot.confirm_enabled = False`），**不是改断言**。

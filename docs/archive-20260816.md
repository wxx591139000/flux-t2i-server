**v1.5 — 商户管理中心 `/admin` + 账户化改造**（成套借鉴转录项目 admin.html + account 模型）

### ① 商户管理中心 `/admin`（借鉴转录项目 admin.html）
用户问"怎么进商户管理中心管理套餐/token"，此前**没有管理网页**。本次新建：
- **鉴权**：`X-Admin-Token` / `Authorization: Bearer` 头 = `WEB_ADMIN_TOKEN`（.env 里 `flux-admin-2026`）
- **激活码**：8 位去混淆字符集（`ABCDEFGHJKMNPQRSTUVWXYZ23456789`）、`status`(unused/active)/`expires_at`/`remark`、生成 `count 1-100` 校验
- **管理面板**：生成码表单 + 全码统计表 + 改备注 + 下钻 + 用户管理 + 最近任务
- 入口：`https://flux.zhuanlu.xyz/admin`（首页右上角「商户管理」）

### ② 账户化改造（借鉴转录项目 account 模型）
解决两大痛点：激活码绑死 token（换设备丢套餐）+ 商家无法按客户管理。
- **激活码=账户**：一客户一账户，客户任意 token「绑定激活码」并入同一账户，多设备**共享一份套餐**
- **用量按账户聚合**：`users.account_id` 列 + `quota.effective()`（绑账户取账户，未绑自账户向后兼容）
- **商家按客户管理**：admin 主表改「客户/账户」维度（账户/客户名/套餐/用量聚合/设备数/详情）

**改动文件**：`manager/flux_db.py`（+190）、`manager/flux_quota.py`（+42）、`manager/flux_web_service.py`（+379）—— 3 文件 +573/-38

**验证**：激活建账户 → 多设备绑定 → 用量聚合 → 账户详情 → set_plan/set_owner → 未绑 token 独立，全链路通过；admin JS 经 `node --check` 校验。

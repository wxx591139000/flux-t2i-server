## 本次归档变更摘要

**v2.0 多服务器化 + VPS 看门狗 + 重启恢复修复**

新克隆第 2 台 FLUX 服务器（flux2，`connect.weste.seetacloud.com:23192`，原 flux1=`autodl-flux`），任务中心从"单机绑定"升级为"多机任选"。

- **任务中心多服务器**：
  - `manager/flux_server_manager.py`：`FLUX_SERVERS` 注册表（默认 flux1+flux2，env `FLUX_SERVERS_JSON` 覆写）+ SSH 操作全部服务器感知 + `probe()/find_ready_server()/any_ready()`
  - `manager/flux_queue.py`：每单 `find_ready_server()` 挑任一台可达+带卡+模型就绪服务器执行，`server` 名回写 DB；`_health_loop` 用 `any_ready()`；新增 `_recover_orphaned_jobs()` 重启不丢 queued/generating 任务

  - 并发策略：单 worker 串行，每单自动选任意可用服务器（用户确认）
- **VPS 看门狗**（新建 `watchdog/`）：`flux_server_ready.sh`（服务器端就绪）+ `flux_watchdog.sh`（VPS 巡检，镜像 qwen watchdog-vps）+ `flux-watchdog.service`（systemd）+ `README.md`。语义=预热就绪+保活，真正生图仍由任务中心按需调度

- **flux2 接入（部分）**：`~/.ssh/config` 已加 `autodl-flux2`；免密+数据盘校验待 clone 完成

# FLUX 文生图服务 · 商家使用 SOP

> 版本：v1.0 · 2026-08-16
> 入口：`https://flux.zhuanlu.xyz/admin`
> 角色：商户 / 管理员（owner）。本文档从「**如何经营客户套餐**」的角度，逐条讲清后台每个按钮的用途与推荐操作。

---

## 一、登录商户中心

### 1. 打开入口
浏览器访问 **`https://flux.zhuanlu.xyz/admin`**（首页右上角也有「商户管理」链接）。

### 2. 管理员登录
- 页面停在一个「管理员登录」框（gate）。
- 输入**管理员 Token**（即 `WEB_ADMIN_TOKEN`，在 `manager/.env` 里，默认 `flux-admin-2026`），点「登录」或回车。
- 登录成功后：
  - Token 会存进浏览器 `localStorage`（变量名 `flux_admin_token`），**下次访问自动带出，无需重复登录**。
  - 所有请求通过请求头 `X-Admin-Token` 传给后台校验。
- 右上角「退出」按钮清除本地 Token，回到登录框。

> ⚠️ 管理 Token 是最高权限，决定套餐/owner/备注，**不要泄露给客户**。换浏览器/清缓存需重新登录。

## 三、给新客户开账户（核心流程）

**核心概念（务必先理解）**：激活码 = 账户 = 一个客户。
- 客户首次用你发的激活码 → 自动建一个账户，该激活码就是账户 ID。
- 客户后续任何设备/浏览器输入同一激活码「绑定」→ 并入同一账户，**多设备共享一份套餐和用量**。
- 所以你**只需给每个客户发一个激活码**，他换不换设备都不影响套餐。

### 操作步骤
1. 进「生成激活码」区。
2. 填 4 个参数：
   - **数量**：生成几个码（1–100）。
   - **天数**：有效期天数（0–365，**0 = 永久不过期**）。
   - **套餐**：`basic(50张/月)` / `pro(200张/月)` / `default(10张/月)`。
   - **备注**：建议直接写**客户名/用途**（如「张三·公众号」），后面账户表会显示成客户名，方便你认人。
3. 点「生成」→ 下方显示新生成的激活码（可逐个复制）。
4. 把激活码发给客户，让他到生成页输入框点「激活 / 绑定」。

> 💡 **推荐做法**：生成时就填好备注，这样客户账户表直接显示客户名，不用二次改。

## 四、客户 / 账户管理（日常经营主战场）

主表每行 = 一个客户账户，列含义：

| 列 | 含义 | 你能做什么 |
|---|---|---|
| **账户(激活码)** | 客户账户 ID（= 当初发的激活码） | — |
| **客户名** | 生成码时备注，可改 | 点「改」→ 弹框输入新客户名 |
| **套餐** | 当前套餐 or 「owner无限」 | 下拉框直接切换套餐 |
| **本月用量** | 本月已用 / 月额度 | 判断客户是否快跑满 |
| **设备数** | 该账户绑定的 token 数（=几台设备） | 判断客户是否多设备 |
| **创建** | 账户创建时间 | — |
| **操作** | 改套餐 / 设owner / 详情 | 见下 |

### 常用操作
- **改套餐**：点该行「套餐」下拉框选新套餐 → 立即生效（同步更新激活码表）。适合客户加钱升级。
- **设 owner（无限量）**：点「设owner」→ 该账户标记为 `owner无限`（橙色徽标），**不限量生成**。适合你自己、或大客户/内部白名单。再点「取消owner」恢复按套餐计。
- **详情（下钻）**：点「详情」→ 展开该账户下**所有绑定的设备 token**（每台设备一行，含各自套餐/本月用量），每台设备可再点「任务」下钻看它生成过什么。
- **搜索**：顶部搜索框按「激活码 / 客户名(token)」搜，命中的行会**黄色高亮**，方便从一大堆客户里快速定位。

> 💡 客户抱怨「换电脑套餐没了」→ 让他新设备上输入**原激活码**点「激活 / 绑定」即可并入原账户，你不用重发码。

## 五、激活码清单（发码/到期管理）

主表下方是全部激活码，列含义：

| 列 | 含义 |
|---|---|
| **激活码** | 8 位去混淆字符，可「复制」直接粘贴发给客户 |
| **套餐** | 该码对应的套餐 |
| **状态** | `可用`（绿）/ `已用`（粉，已被某账户激活）/ `已过期`（红） |
| **备注** | 客户名/用途，点「备注」可改 |
| **到期** | 有效期截止（`永久`= 不过期） |
| **使用人** | 激活该码的账户 ID（= 激活码本身）+ 激活时间 |
| **操作** | 点「账户」跳到该客户的账户详情 |

- **复制**：一键把码复制到剪贴板，直接微信/邮件发给客户。
- **已用**的码点「账户」→ 直接看到是哪个客户、他名下所有设备和用量。

## 六、最近任务（看生成情况）

最近 50 条任务，列：任务ID / 用户(token) / 状态 / 提示词 / 时间。
- 状态：`排队中` / `生成中` / `等待服务恢复` / `已完成` / `失败`。
- 点账户详情的「任务」按钮，会**过滤**此表只显示该 token 的任务，方便排查某客户。

## 七、异常排查速查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 客户说「提交被拒，达到月度配额」 | 该账户本月额度用满 | 账户表找到 TA → 下拉改套餐 或 设owner |
| 客户说「换设备套餐没了」 | 新设备没绑账户 | 让客户输入原激活码「绑定」 |
| 客户说激活码无效/过期 | 码天数到期，或码已用 | 激活码表看状态 → 重新生成新码 |
| 任务一直「等待服务恢复」 | FLUX 服务器关机/失效 | 去服务器开机，健康监控会自动恢复重排 |
| 点「生成」没反应/登录没反应 | 存档 JS 语法出错（本版已修） | 刷新页面；仍不行重启服务 |

## 八、API 方式批量操作（可选，给脚本/自动化用）

所有管理操作都可用 curl 调，`admin_token` 填管理 Token：

```bash
# 生成 5 个 basic 码，30 天，备注"张三"
curl -s -X POST https://flux.zhuanlu.xyz/api/admin/gen_codes \
  -H "Content-Type: application/json" \
  -d '{"admin_token":"flux-admin-2026","plan":"basic","n":5,"days":30,"remark":"张三"}'

# 改某账户套餐为 pro
curl -s -X POST https://flux.zhuanlu.xyz/api/admin/set_plan \
  -H "Content-Type: application/json" \
  -d '{"admin_token":"flux-admin-2026","account_id":"激活码","plan":"pro"}'

# 设某账户为 owner（无限）
curl -s -X POST https://flux.zhuanlu.xyz/api/admin/set_owner \
  -H "Content-Type: application/json" \
  -d '{"admin_token":"flux-admin-2026","account_id":"激活码","is_owner":true}'

# 改客户名
curl -s -X POST https://flux.zhuanlu.xyz/api/admin/set_remark \
  -H "Content-Type: application/json" \
  -d '{"admin_token":"flux-admin-2026","code":"激活码","remark":"李四-小红书"}'
```

> Token 也可用请求头方式：`-H "X-Admin-Token: flux-admin-2026"`，两者等价。

## 九、安全与维护约定

- **管理 Token 不硬编码在网页里**，只在你的 `manager/.env` 和登录后浏览器 localStorage。
- 不要把你的管理 Token 发给客户；客户用激活码即可。
- 改套餐/设owner 会用对账双向同步（账户表 + 激活码表），操作后刷新看状态确认。
- 本服务挂**本地 xhs-tunnel 隧道**（`flux.zhuanlu.xyz → localhost:9620`），隧道/服务重启见 `docs/WEB_SERVICE.md`。

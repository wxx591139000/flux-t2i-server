# FLUX 文生图服务 · 用户使用 SOP

> 版本：v1.0 · 2026-08-16
> 入口：`https://flux.zhuanlu.xyz`
> 角色：普通用户（浏览器操作，无需安装任何软件）。本文档从「**从零到生成一张图**」讲起，含套餐/账户/换设备说明。

---

## 一、打开页面，认识你的身份

访问 **`https://flux.zhuanlu.xyz`**。

- 首次访问，浏览器会自动给你生成一个 **Token**（一串 16 位字符），并存入浏览器 Cookie（有效期一年）。
- 页面顶部显示：`你的Token: xxx · 套餐: default · 用量: 0/10`。
  - **Token 就是你的身份标识**，后台靠它认你是谁、扣谁的用量。
  - 换浏览器 / 清 Cookie / 换设备 = 得到一个新 Token（新身份）。
- 下方绿色小字会显示你当前是否已绑定账户。

---

## 二、生成你的第一张图（5 步）

1. 在「生成图片」输入框里，**用英文描述**你想要的图。
   - 示例：`a cute shiba inu running on a beach, cinematic lighting, photorealistic`
   - 💡 也可以**直接输入中文**（如「一只橘猫坐在窗台上」），系统会自动翻译成英文再生成。
   - 描述越具体（主体 + 场景 + 光线 + 风格）效果越好。
2. 点「提交生成」按钮。
3. 看到绿色提示 `已入队，任务ID: xxx` → 说明成功进入队列。
4. 等生成：
   - 页面下方「我的任务」表格会**自动刷新**。
   - 状态流转：`排队中 → 生成中 → 已完成`。
   - 每张约 **85 秒**（GPU 单卡串行，人多时排队依次执行，属正常）。
   - 若服务器临时关机，会显示 `等待服务恢复`，恢复后自动继续，**无需你操作**。
5. 完成后，任务行内直接显示图片，点 **「⬇ 下载」** 保存到本地。

> 💡 想看更多历史：点顶部「我的任务中心」（`/center`），可回看最近 50 条。

## 三、套餐与额度

- 每个套餐对应**每月可生成的图片数**：
  - `default` = 10 张/月
  - `basic` = 50 张/月
  - `pro` = 200 张/月
- **每提交一张，当月额度就扣 1 张**（提交时即扣，与是否生成成功无关，请谨慎提交）。
- 用满后再次提交会被拒绝，提示「达到月度配额」。
- 跨月自动重置（按自然月）。

## 四、激活码：「激活 / 绑定账户」

商家（卖你服务的人）会发给你一个 **激活码**（8 位字符，如 `ABCD1234`）。

### 场景 A：第一次用（新客户开通）
1. 把激活码粘贴到「激活 / 绑定账户」输入框。
2. 点「激活 / 绑定」。
3. 提示 `激活成功，套餐: xxx` → 开通成功，套餐升级、额度增加。

### 场景 B：换设备 / 换浏览器（老客户）
- **你的套餐是绑在「账户」上的，不是绑在某台设备上**。
- 只要在新设备上**输入同一个激活码**，点「激活 / 绑定」→ 提示 `已绑定到已有账户，共享套餐: xxx`。
- 新设备并入同一账户，**和你原来那台设备共享同一份套餐和用量**，不会重开、不重复扣额度。

> 💡 激活码 = 你的账户。**务必妥善保存**，换设备全靠它。页面顶部会显示你当前绑定的账户码。

## 五、常见问题（FAQ）

| 问题 | 原因 / 解决办法 |
|---|---|
| 提交被拒「达到月度配额」 | 本月额度用完了，联系商家升级套餐或下月再用 |
| 换电脑后套餐变成 default | 新设备是新身份，输入原激活码点「绑定」即可 |
| 提示「激活码无效、已过期 」 | 码过期或已被占用，联系商家要新码 |
| 任务一直「等待服务恢复」 | 生成服务器关机了，恢复后自动继续，稍等即可 |
| 生成的图不是我要的 | 提示词尽量写清楚主体+场景+光线+风格；中文也能用 |
| 想批量生成很多张 | 逐条提交即可，系统自动排队串行处理 |

## 六、给程序用户的 API（可选）

如果你不是用浏览器，而是写程序调用，可用以下接口（token 放 query 或 Cookie）：

```bash
# 提交任务
curl -s -X POST "https://flux.zhuanlu.xyz/api/submit?token=你的token" \
  -H "Content-Type: application/json" -d '{"prompt":"a red fox"}'
# → {"job_id":"...","status":"queued"}

# 轮询状态
curl -s "https://flux.zhuanlu.xyz/api/status?job_id=任务ID"

# 下载图片（token 必须与该任务属主一致）
curl -s -o fox.png "https://flux.zhuanlu.xyz/api/download/任务ID?token=你的token"

# 查看自己的账户/套餐/用量
curl -s "https://flux.zhuanlu.xyz/api/my?token=你的token"
```

> ⚠️ 下载图片时校验归属：**token 必须和提交时的 token 一致**，否则返回 403 无权访问。

## 七、隐私与安全

- 你的 Token 存在本地浏览器 Cookie，是访问凭证，**不要泄露**。
- 激活码是账户凭证，换设备全靠它，**妥善保存**。
- 系统只存储你的提示词、生成结果和用量，用于提供服务和计费。
